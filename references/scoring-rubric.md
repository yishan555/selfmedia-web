# 内容质量打分 Rubric

## 评分体系

6 维度加权，每维 0-5 分，综合分 = 加权平均 × 2（满分 10 分）。

总权重 = 1.0 + 1.5 + 1.0 + 1.0 + 1.5 + 1.5 = **7.5**

---

## 维度 1：信息密度 (information_density) — 权重 ×1.0

| 分数 | 标准 |
|------|------|
| 0 | 无任何有效信息 |
| 1 | 大量废话，核心信息 < 20% |
| 2 | 有一些信息但不够聚焦 |
| 3 | 有干货，信息量适中 |
| 4 | 信息密度高，多个有价值的观点/数据 |
| 5 | 极高价值，几乎每句话都有信息增量 |

**加分项**：独特数据、原创分析、定量对比、案例支撑
**减分项**：废话套话、重复表述、缺乏数据支撑

---

## 维度 2：标题吸引力 (hook_power) — 权重 ×1.5

| 分数 | 标准 |
|------|------|
| 0 | 无感，完全没有点击欲望 |
| 1 | 平淡，像新闻标题 |
| 2 | 一般，有点信息但不吸引 |
| 3 | 有吸引力，使用了某种 hook 技巧 |
| 4 | 很强，信息差 + 好奇心缺口明显 |
| 5 | 无法抗拒，必须点开看 |

**加分项**：数字、对比、反常识、利益承诺、紧迫感
**减分项**：太长、太模糊、太标题党（无法兑现）

---

## 维度 3：视觉表现力 (visual_appeal) — 权重 ×1.0

| 分数 | 标准 |
|------|------|
| 0 | 无图或图片与内容完全无关 |
| 1 | 有图但质量很差（模糊、无关、水印） |
| 2 | 有基本配图，尚可 |
| 3 | 配图质量好，与内容匹配 |
| 4 | 专业水准，排版精美，信息图有价值 |
| 5 | 出色，视觉本身就是内容，令人印象深刻 |

**加分项**：信息图、数据可视化、产品高清图、统一色调
**减分项**：水印、低分辨率、配图与内容不匹配、过多文字截图

---

## 维度 4：受众匹配度 (audience_fit) — 权重 ×1.0

| 分数 | 标准 |
|------|------|
| 0 | 完全不匹配目标受众 |
| 1 | 勉强相关，但太浅或太深 |
| 2 | 一般匹配，语言或深度有偏差 |
| 3 | 匹配，目标读者会感兴趣 |
| 4 | 很匹配，命中痛点/兴趣点 |
| 5 | 精准命中，读者会主动分享 |

**目标读者画像**：对科技/设计/前沿趋势感兴趣的年轻专业人士（25-40 岁）

**加分项**：实用建议、行业洞察、独特视角、可操作的 takeaway
**减分项**：过于学术化、纯搬运无观点、与领域无关、认知落差小（"这个我知道"）

**认知落差检查**：同行把这个事情讲清楚了吗？我的表达比同行好在哪？受众看完会不会觉得
"这个我早就知道了"？有明显落差才配得上 4/5 分。

---

## 维度 5：情感共鸣 (emotional_resonance) — 权重 ×1.5

| 分数 | 标准 |
|------|------|
| 0 | 完全无感，纯机械信息罗列 |
| 1 | 略有触动，但平铺直叙 |
| 2 | 一般，有些情绪但不深入 |
| 3 | 有共鸣，能引发读者情感回应 |
| 4 | 强共鸣，触及行业人群共同痛点或兴奋点 |
| 5 | 深度触动，读者会想评论表达感受 |

**加分项**：个人故事/经历、行业痛点共情、未来展望激动感、"终于有人说了"感
**减分项**：冷冰冰的转述、与读者无关的情感、强行煽情

> 共鸣机制：是否说出了目标读者难以表达的真实处境（沉默解除），
> 是否回应其实际需求（满足动机）。仍须按本节锚点评分，不以煽情代替事实。

---

## 维度 6：社交传播力 (social_shareability) — 权重 ×1.5

| 分数 | 标准 |
|------|------|
| 0 | 不会有人转发 |
| 1 | 勉强可转，但无动力 |
| 2 | 一般，小范围可能分享 |
| 3 | 愿意分享，有社交货币属性 |
| 4 | 主动转发，"这个你一定要看" |
| 5 | 必须分享，不转不行（信息差 / 实用性 / 震撼感） |

**加分项**：独家信息、实用清单、反常识结论、可截图金句、数据首发
**减分项**：人人都知道的信息、无法独立理解（需要上下文）、过于小众

> 传播机制：明确谁会第一个转发、转给谁以及为什么；检查内容是否帮助读者
> 表达立场或理解问题（信念结构）。传播假设不能当作已发生的传播效果。

---

## 门控阈值

- 默认阈值：**7.0**（综合分）
- 等价于加权平均 3.5 分（"良好"水平）
- 可在 `config/topics.yaml` 中调整
- 高权重维度（hook_power、emotional_resonance、social_shareability）对综合分影响更大——这符合传播逻辑：再好的内容没人点开/分享就没有价值
